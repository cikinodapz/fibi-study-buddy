# 🌟 Fibi Study Buddy

**Fibi Study Buddy** adalah sebuah ekstensi browser (Chrome/Edge) produktivitas berbasis teknik Pomodoro yang menampilkan karakter **Phoebe (Fibi)** dari game *Wuthering Waves* dalam bentuk *chubby/chibi* yang menggemaskan! 

Berbeda dengan ekstensi Pomodoro biasa yang berupa *pop-up* dan mudah tertutup saat berganti tab, Fibi hadir sebagai **Floating Widget (Widget Melayang)** yang akan terus menemanimu di layar saat kamu membuka halaman web.

---

## ✨ Fitur Utama

- ⏱️ **Timer Pomodoro:** 25 Menit Fokus (Kerja/Belajar) & 5 Menit Istirahat.
- 🎨 **Floating & Draggable Widget:** Widget melayang yang bisa kamu geser-geser (*drag*) ke mana saja di layar agar tidak menghalangi pekerjaanmu.
- 🎭 **Dynamic Character State:**
  - **Focus Mode:** Fibi akan menemanimu fokus dengan gaya serius (sedang menulis/belajar).
  - **Break Mode:** Fibi akan berubah menjadi mode santai (rebahan di beanbag sambil minum teh).
- 🔔 **Notifikasi Otomatis:** Memberitahukan kapan waktunya bekerja dan kapan waktunya istirahat (meskipun kamu sedang membuka tab lain).
- ⚡ **Ringan & Cepat:** Dibangun murni menggunakan Vanilla JavaScript dan CSS tanpa membebani browser.

---

## 🚀 Cara Instalasi (Manual)

Karena ekstensi ini dijalankan secara lokal, kamu bisa menginstalnya secara manual di browser berbasis Chromium (Google Chrome, Microsoft Edge, Brave, dll).

1. **Clone atau Download** *repository* ini ke komputer kamu dan ekstrak foldernya.
2. Buka browser kamu dan masuk ke halaman Ekstensi:
   - **Chrome:** Ketik `chrome://extensions/` di address bar.
   - **Edge:** Ketik `edge://extensions/` di address bar.
3. Aktifkan **Developer mode** (Mode Pengembang) di pojok kanan atas.
4. Klik tombol **Load unpacked** (Muat yang belum dikemas).
5. Pilih folder tempat kamu menyimpan *repository* ini.
6. Voila! Ekstensi berhasil dipasang. 🎉

---

## 💡 Cara Menggunakan

1. Buka website apa saja (seperti Google, Wikipedia, atau Github).
   > *Catatan: Widget tidak akan muncul di halaman internal browser seperti "New Tab" atau halaman pengaturan (chrome://).*
2. Widget **Fibi Study Buddy** akan otomatis melayang di pojok kanan bawah.
3. Klik tombol **Play (▶)** untuk memulai timer fokus selama 25 menit.
4. Kamu bisa menggeser widget dengan menahan klik (drag) pada area **"≡ Drag ≡"** di bagian atas widget.
5. Jika waktu habis, akan muncul notifikasi sistem dan mode akan otomatis berganti ke istirahat.
